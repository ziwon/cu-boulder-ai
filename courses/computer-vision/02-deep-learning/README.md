# 02 — Deep Learning for Computer Vision

## Learning Goals

- Understand MLPs and CNNs from first principles.
- Follow forward/backward propagation well enough to debug training behavior.
- Understand why architectures such as ResNet and U-Net work.
- Relate architecture choices to compute, memory, and inference latency.

## Experiments

Potential extensions:

- Train a small CNN from scratch.
- Compare a plain CNN with MobileNet/ResNet.
- Track parameter count, VRAM, GPU utilization, and inference latency.
