# Computer Vision Specialization

Course notes should stay concise and focus on concepts that are easy to forget or worth re-deriving.

For each course, prefer this pattern:

```text
README.md     concise concept map and takeaways
notebooks/    added only when an experiment is useful
assets/       diagrams/images created during study, if needed
```

Avoid copying course material verbatim. Write explanations in your own words and keep independent experiments separate from graded assignments.
