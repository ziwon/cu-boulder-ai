# 01 — Introduction to Computer Vision

## Learning Goals

- Understand how images are represented numerically.
- Connect linear algebra to image operations.
- Understand convolution before treating CNNs as a black box.
- Learn the basic CV problem families: classification, detection, and segmentation.
